# Release status — 10 November 2026

This standalone selection preserves the completed SFT v3 evaluation. It has no Git directory or inherited development history. The reviewed code is public at https://github.com/RicciYazigi/aegistune-public and the recorded replay is public at https://huggingface.co/spaces/RicciYazigi/aegistune-evidence . Model/data Hub collections and submission remain pending.

SFT v3 remains the selected adapter (182/200 reserved missions). Subsequent GRPO attempts have not produced a completed, reload-verified and development-evaluated replacement. They must not be described as an improvement over v3. A train-only 96-episode exploration found reward contrast in supervisory-proposal cases; that diagnostic is not new held-out validation.

The accompanying static Space package is recorded evidence replay, not live inference. Live inference and stronger independent evaluation remain pending. No video is required by this project's current delivery priorities.
