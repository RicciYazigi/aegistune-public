# AegisTune contributor instructions

Read README.md, CONTRIBUTING.md, docs/CONTRACTS.md and the relevant evaluation documentation. Preserve frozen datasets, recorded results and historical source snapshots. Keep model proposals, gateway permissions, committed effects and mission outcomes distinct. Use fresh episode state and record attempts before rejection. Run focused CPU checks with OMP_NUM_THREADS=1 and MKL_NUM_THREADS=1. Never commit credentials or acquire paid compute without explicit authorization. Model publication and submission require owner approval.
